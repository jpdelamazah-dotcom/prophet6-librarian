# Prophet 6

App web para el Sequential Prophet‑6: biblioteca de presets (lectura por SysEx), clasificación, origen de packs (GEOSynths, Luftrum 15, fábrica), panel, mapa MIDI, recetas, globales y tempo por preset.

**Abrir:** https://jpdelamazah-dotcom.github.io/prophet6-librarian/

- **Mac:** Chrome → abre el link → menú ⋮ → *Transmitir, guardar y compartir* → *Instalar página como app*.
- **iPad:** app *Web MIDI Browser* (App Store) → activa SysEx en sus ajustes → abre el link.

Por seguridad la app parte en modo «Solo ver»: no escribe nada en el Prophet salvo que elijas «Editar» y confirmes.

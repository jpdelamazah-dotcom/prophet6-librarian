Registro de actividad

Botón «Escuchar»

Al cambiar de sonido, el Prophet cambia en silencio. Solo al pulsar ▶ o «Escuchar» (o la barra espaciadora) la app toca un acorde corto (o una nota en bajos) para que lo oigas sin tocar el teclado. Requiere el modo «Escuchar» o «Editar».

Claude dentro de la app

Para crear recetas desde la pestaña Recetas (pegando una captura o describiendo un sonido), la app se conecta a Claude con tu clave de API de Anthropic. Se obtiene en console.anthropic.com → API Keys y se cobra aparte de tu plan de claude.ai. La clave queda guardada solo en este navegador.
